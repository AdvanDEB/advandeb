_Rationale:_ The corpus provides strong, multiple supporting references for the stylized fact that egg size / initial reserve covaries with maternal nutritional status. The core DEB maternal-effect rule—that reserve density at birth equals the mother's reserve density at egg formation, so well-fed mothers produce well-fed offspring—is stated explicitly across several foundational sources (snippets 9, 13, 15, 18) and empirically corroborated in Daphnia (6, 7) and Daphnia/copepod growth models (2). Several snippets, however, note exceptions where some species (poeciliid fishes, daphnids, Sancassania mites) produce larger eggs under poor feeding, and direct measurements (5, 13, 14, 16) show egg size/volume decreasing with increasing food—an inverse relationship that partly contradicts a simple positive covariation. Despite these documented exceptions, the dominant pattern affirmed in the DEB literature is that egg reserve covaries with maternal nutritional status, so the consensus is corroborative while acknowledging recognized counterexamples.
